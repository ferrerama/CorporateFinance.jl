Cost of capital

CAPM

\[k_e = r_f + \beta \cdot ERP + CRP\]

CorporateFinance.capm — Function
capm(; rf::Real, beta::Real, erp::Real, crp::Real)

Calculates the Cost of Equity using the Capital Asset Pricing Model (CAPM).

Keyword Arguments

  • rf: Risk-free rate. Can be negative.
  • beta: Systematic risk measure. Must be between -5 and 5.
  • erp: Equity Risk Premium. Cannot be negative.
  • crp: Country Risk Premium. Cannot be negative.

WACC

\[WACC = \frac{E}{E + D}\, k_e + \frac{D}{E + D}\, k_d\, (1 - t)\]

CorporateFinance.wacc — Function
wacc(; ke::Real, kd::Real, tax::Real, E::Real, D::Real)

Calculates the Weighted Average Cost of Capital (WACC).

Keyword Arguments

  • ke: Cost of Equity.
  • kd: Cost of Debt.
  • tax: Corporate tax rate, between 0 and 1.
  • E: Market value of equity.
  • D: Market value of debt.

Beta regression

\[\beta = \frac{\operatorname{cov}(r_a, r_m)}{\operatorname{var}(r_m)}\]

CorporateFinance.beta_regression — Function
beta_regression(asset_returns::AbstractVector{<:Real}, market_returns::AbstractVector{<:Real})

Calculates the beta of an asset relative to the market: cov(asset_returns, market_returns) / var(market_returns).

Arguments

  • asset_returns: Periodic returns of the asset.
  • market_returns: Periodic returns of the market index, same length and periods as asset_returns.

Unlevered and relevered beta

Hamada equation, extended with an optional debt beta $\beta_D$ (Conine). With $\beta_D = 0$ (the default) it reduces to the classic Hamada formula.

\[k = (1 - t)\, D/E \qquad \beta_U = \frac{\beta_L + \beta_D\, k}{1 + k} \qquad \beta_L = \beta_U + (\beta_U - \beta_D)\, k\]

CorporateFinance.unlever_beta — Function
unlever_beta(; beta::Real, tax::Real, E::Real, D::Real, beta_debt::Real = 0)

Removes the effect of debt from a levered beta: (beta + beta_debt * k) / (1 + k), with k = (1 - tax) * D / E.

With beta_debt = 0 this is the Hamada equation. A positive beta_debt (Conine formula) is more realistic for highly leveraged companies, whose debt carries part of the business risk.

Keyword Arguments

  • beta: Levered (observed) beta.
  • tax: Corporate tax rate, between 0 and 1.
  • E: Market value of equity.
  • D: Market value of debt.
  • beta_debt: Beta of the debt. Defaults to 0 (risk-free debt).
source
CorporateFinance.relever_beta — Function
relever_beta(; beta::Real, tax::Real, E::Real, D::Real, beta_debt::Real = 0)

Applies a target capital structure to an unlevered beta: beta + (beta - beta_debt) * k, with k = (1 - tax) * D / E. It is the inverse of unlever_beta.

Keyword Arguments

  • beta: Unlevered beta.
  • tax: Corporate tax rate, between 0 and 1.
  • E: Target value of equity.
  • D: Target value of debt.
  • beta_debt: Beta of the debt. Defaults to 0 (risk-free debt).
