Perpetuity

\[PV = \frac{CF}{r}\]

CorporateFinance.perpetuity — Function
perpetuity(cashflow::Real, rate::Real)

Calculates the present value of a constant perpetuity: cashflow / rate.

Arguments

  • cashflow: Constant cash flow received each period.
  • rate: Discount rate. Must be positive.

Terminal value

Gordon growth model, applied to the free cash flow of the last forecast year:

\[TV_n = \frac{FCF_n\,(1 + g)}{WACC - g}\]

CorporateFinance.terminal_value — Function
terminal_value(; fcf::Real, wacc::Real, g::Real)

Calculates the terminal value at the end of the forecast period using the Gordon growth model: fcf * (1 + g) / (wacc - g).

Keyword Arguments

  • fcf: Free cash flow of the last forecast year.
  • wacc: Discount rate. Must be greater than g.
  • g: Long-term growth rate.
source

DCF valuation

Two stages: the forecast free cash flows and the terminal value.

\[EV = \sum_{t=1}^{n} \frac{FCF_t}{(1 + WACC)^t} + \frac{TV_n}{(1 + WACC)^n}\]

CorporateFinance.dcf_valuation — Function
dcf_valuation(fcf::AbstractVector{<:Real}; wacc::Real, g::Real)

Values a company with a discounted cash flow model in two stages: the forecast free cash flows and a terminal value (Gordon growth) after the last year.

Returns a named tuple with pv_fcf, pv_terminal and enterprise_value.

Arguments

  • fcf: Forecast free cash flows, one per year (year 1 to n).

Keyword Arguments

  • wacc: Discount rate. Must be greater than g.
  • g: Long-term growth rate after the forecast period.
source

Equity value

\[\text{Equity} = EV - \text{Debt} + \text{Cash}\]

CorporateFinance.equity_value — Function
equity_value(; ev::Real, debt::Real, cash::Real = 0)

Calculates the equity value from the enterprise value: ev - debt + cash.

Keyword Arguments

  • ev: Enterprise value.
  • debt: Total financial debt. Cannot be negative.
  • cash: Cash and equivalents. Cannot be negative.
