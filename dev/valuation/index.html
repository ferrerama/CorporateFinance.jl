Terminal value

Gordon growth model, applied to the free cash flow of the last forecast year:

\[TV_n = \frac{FCF_n\,(1 + g)}{WACC - g}\]

CorporateFinance.terminal_value — Function
terminal_value(; fcf::Real, wacc::Real, g::Real)

Calculates the terminal value at the end of the forecast period using the Gordon growth model: fcf * (1 + g) / (wacc - g).

Keyword Arguments

  • fcf: Free cash flow of the last forecast year.
  • wacc: Discount rate. Must be greater than g.
  • g: Long-term growth rate.

Fade stage

A transition stage between the explicit forecast and the terminal value, in which growth declines from $g_0$ to $g$ in linear increments over $m$ years, reaching $g$ in the last year of the stage:

\[g_k = g_0 + (g - g_0)\,\frac{k}{m}, \qquad FCF_{n+k} = FCF_{n+k-1}\,(1 + g_k), \qquad k = 1, \dots, m\]

CorporateFinance.fade_forecast — Function
fade_forecast(; fcf::Real, g_start::Real, g::Real, years::Integer)

Extends a forecast with a transition stage in which growth declines from g_start to the long-term rate g in linear increments. Returns years free cash flows, the growth rate of year k being g_start + (g - g_start) * k / years, so the last year of the stage already grows at g.

For example, g_start = 0.30, g = 0.05 and years = 5 give growth rates of 25%, 20%, 15%, 10% and 5%.

Append the result to the explicit forecast to build a three-stage DCF: dcf_valuation(vcat(fcf, fade_forecast(...)); wacc, g).

Keyword Arguments

  • fcf: Free cash flow of the last explicit forecast year.
  • g_start: Growth rate of the high-growth stage (the last explicit forecast year).
  • g: Long-term growth rate, reached in the last year of the stage.
  • years: Length of the stage. Must be at least 1.

DCF valuation

The forecast free cash flows plus the terminal value, either with Gordon growth or with an exit multiple:

\[EV = \sum_{t=1}^{n} \frac{FCF_t}{(1 + WACC)^t} + \frac{TV_n}{(1 + WACC)^n}, \qquad TV_n = \text{Multiple} \times \text{EBITDA}_n \;\text{(exit multiple)}\]

With the mid-year convention the exponents become $t - 0.5$ (and $n - 0.5$ for a Gordon terminal value).

CorporateFinance.dcf_valuation — Function
dcf_valuation(fcf::AbstractVector{<:Real}; wacc::Real, g = nothing,
              exit_multiple = nothing, ebitda = nothing, midyear::Bool = false)

Values a company with a discounted cash flow model: the forecast free cash flows plus a terminal value after the last year. The terminal value is calculated either with the Gordon growth model (pass g) or with an exit multiple (pass exit_multiple and ebitda), but not both.

With midyear = true the cash flows are discounted at t - 0.5, as if they were received in the middle of each year. A Gordon terminal value is then also discounted at n - 0.5, while an exit-multiple terminal value stays at n, since it represents a sale price at the end of the last year.

Returns a named tuple with pv_fcf, pv_terminal and enterprise_value.

Arguments

  • fcf: Forecast free cash flows, one per year (year 1 to n).

Keyword Arguments

  • wacc: Discount rate. Must be greater than -1, and greater than g if given.
  • g: Long-term growth rate after the forecast period.
  • exit_multiple: EV/EBITDA multiple applied at the end of the forecast. Cannot be negative.
  • ebitda: EBITDA of the last forecast year, used with exit_multiple.
  • midyear: Use the mid-year discounting convention. Defaults to false.

Sensitivity table

CorporateFinance.dcf_sensitivity — Function
dcf_sensitivity(fcf::AbstractVector{<:Real}; waccs::AbstractVector{<:Real},
                gs::AbstractVector{<:Real}, midyear::Bool = false)

Builds the classic sensitivity table of a DCF: the enterprise value for each combination of discount rate (rows) and long-term growth rate (columns), using dcf_valuation with a Gordon terminal value.

Combinations where wacc <= g have no valid Gordon value and are returned as NaN, so the rest of the table is still produced.

Arguments

  • fcf: Forecast free cash flows, one per year (year 1 to n).

Keyword Arguments

  • waccs: Discount rates, one per row.
  • gs: Long-term growth rates, one per column.
  • midyear: Use the mid-year discounting convention. Defaults to false.

Equity value

\[\text{Equity} = EV - \text{Debt} + \text{Cash} - \text{Minority interest} - \text{Preferred} - \text{Leases} + \text{Non-operating assets}\]

CorporateFinance.equity_value — Function
equity_value(; ev::Real, debt::Real, cash::Real = 0, minority_interest::Real = 0,
             preferred::Real = 0, leases::Real = 0, non_operating::Real = 0)

Calculates the equity value from the enterprise value: ev - debt + cash - minority_interest - preferred - leases + non_operating.

Only subtract leases (IFRS 16 lease liabilities) if the free cash flows were calculated before lease payments; otherwise they would be counted twice.

Keyword Arguments

  • ev: Enterprise value.
  • debt: Total financial debt.
  • cash: Cash and equivalents.
  • minority_interest: Non-controlling interests in consolidated subsidiaries.
  • preferred: Preferred stock.
  • leases: Lease liabilities.
  • non_operating: Non-operating assets (e.g. investments not included in the cash flows).

All arguments except ev cannot be negative and, except debt, default to 0.
